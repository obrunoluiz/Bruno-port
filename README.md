# Bruno Port — No Code Pages

Reprodução local da landing page de referência:
https://designagora.onlineaprender.com/webdesign/

## Executar

```bash
npm start
```

A página ficará disponível em `http://localhost:4173`. O comando gera e
serve exatamente a mesma versão estática usada pela Vercel.

## Produção

Use `https://bruno-port.vercel.app` sem `www`. O endereço
`https://www.bruno-port.vercel.app` não é um domínio válido do projeto e
falha na validação do certificado HTTPS.

> A reprodução preserva os recursos visuais hospedados pela página de referência
> para manter máxima fidelidade ao original.
